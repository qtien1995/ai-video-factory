# Idea Workflows

## Key Expansion

Use when the user is stuck with a generic product/topic.

1. Start with the direct key: product, service, niche, or message.
2. Expand to adjacent keys:
   - usage situation
   - user type
   - location
   - time or season
   - object/tool involved
   - conflict, obstacle, mistake
   - before/after state
   - emotion
   - social relationship
   - proof, number, certificate, review
3. Combine 2-4 expanded keys into one premise.
4. Add a concept: comparison, journey, warning, number, hot topic, useful, strange, certification, etc.
5. Write the first sentence/title before writing the body.

Example pattern:

- Product key: mì tôm
- Expanded keys: sinh viên, cốc, nước sôi, mẹ đi chợ, đêm khuya, ký túc xá
- Premise: "Có một loại quà mẹ mua ngoài chợ khiến sinh viên nhớ nhà hơn cả tiền gửi."

## 5W1H Idea Matrix

Use this to turn audience pain into post titles.

| Field | Question |
|---|---|
| What | What problem, product, behavior, or result is being discussed? |
| Who | Who feels this most strongly? |
| Why | Why does it matter now? |
| When | When does this pain/desire appear? |
| Where | Where does the viewer experience it? |
| How | How can the content help, dramatize, or prove it? |

## DCIK Formula

DCIK = đối tượng + concept truyền thông + insight + keyword/context.

Good output should make all 4 visible:

- Audience: "newbie content dưới 3 năm kinh nghiệm"
- Concept: "cảnh báo + số"
- Insight: "sợ bí ý tưởng và bị đánh giá kém"
- Keyword/context: "7 dấu hiệu bạn đang viết content như người mới"

## Testing Rules

- Test topic and format separately when possible.
- Keep one repeatable format for several posts before declaring failure.
- A high-view idea that attracts the wrong audience is not a win for conversion.
- Store high-performing hooks, titles, first frames, comments, and objections as raw material for later posts.
