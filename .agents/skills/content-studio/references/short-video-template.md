# Short Video Template

## 15-30 Second Structure

| Time | Purpose | Notes |
|---|---|---|
| 0-3s | Hook | Surprise, pain, question, result, or emotional action |
| 3-7s | Context | Who/what/why should viewer care |
| 7-20s | Value/tension | Steps, proof, contrast, story beats, mistake, transformation |
| 20-27s | Payoff | Result, lesson, reveal, answer |
| 27-30s | CTA | Save, follow, comment, DM, link, part 2 |

## Hook Types

- Pain: "Nếu bạn đang [problem], đừng làm điều này."
- Result: "Đây là cách [person] đi từ [before] đến [after]."
- Curiosity: "Không ai nói với bạn điều này về [topic]."
- Comparison: "[A] và [B] khác nhau ở đúng 1 điểm."
- Story: "Hôm đó tôi nhận ra [lesson] theo cách rất đau."
- Warning: "3 dấu hiệu cho thấy [risk]."
- Proof: "Chúng tôi test [thing] trong [time] và kết quả là..."

## Shot List Prompts

- What should the viewer see before hearing the explanation?
- Which object, screen, face, gesture, or result proves the claim?
- Can one visual detail replace one sentence?
- Where does the product/brand appear naturally?

## Caption Formula

- Restate hook in shorter form.
- Add one useful detail or context.
- CTA: save, comment, ask, DM, follow, read part 2.
