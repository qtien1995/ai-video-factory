# Facebook Reels Principles

From the Reels PDF: Reels is not only a format, it is a style.

## Reels Style

Strong Reels are:

- entertaining: surprise, delight, fresh angle
- easy to understand: immediate message, simple visual logic
- empathetic: recognizable situation, human tone, familiar motif

## First 3 Seconds

Use one of:

- unexpected visual
- clear useful promise
- relatable problem
- emotional action
- comparison or before/after

## Brand/Product Placement

- Make the product or brand easy to notice without interrupting the viewer experience.
- Place the product in use, inside a situation, process, result, or story.
- Avoid logo-only intros.

## Story and Execution

- "Tả mà không kể": show the detail instead of explaining it.
- Keep the message instantly understandable.
- Add a clear CTA for ads or conversion videos.
- Repurpose existing assets by changing pacing, first frame, text overlay, and story order for Reels style.
