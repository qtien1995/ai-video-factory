# Gen Video Component Library

Reusable Remotion primitives will live here as Gen Video matures.

Examples:

- KineticHeadline
- AnimatedNumber
- ChartEngine
- MapEngine
- ImageAnnotation
- CutoutParallax
- Timeline
- DataFlow
- EditorialCollage

Register reusable components in:

`D:\VIDEO AI\config\component-index.json`

Principle:

**Reuse technology. Reinvent storytelling.**
