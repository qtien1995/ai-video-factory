# Creative Library

Thư viện lưu **creative grammar** đã phân tích/được chứng minh, không phải kho clip để copy.

```text
creative-library/
  references/<reference-id>/analysis.json
  motion-stories/        # pattern kể chuyện đã được kiểm chứng
  visual-skins/          # palette, typography, texture; không quyết định story
  primitives/            # draw, flow, fill, split, count, camera focus...
  patterns/pattern-index.json
```

Mỗi reference cần Motion DNA: core object, lifecycle, continuity, motion/camera grammar, text dependency, slide-risk, reusable primitives và `doNotCopy`.

Chỉ promote pattern/primitives sau khi đã dùng thành công trong video thực tế.
